# Анализ лояльности пользователей Яндекс Афиши

## Цель проекта
Провести исследовательский анализ лояльности пользователей Яндекс Афиши для выявления факторов, влияющих на повторные покупки.

## Основные задачи:
- Загрузить данные и провести их первичный осмотр.
- Провести предобработку данных.
- Провести исследовательский анализ данных:
- Проанализировать воронку событий от первого визита до покупки.
- Рассчитать и проанализировать ключевые метрики лояльности.
- Провести сегментацию пользователей.
- Исследовать, как различные характеристики пользователей (источник привлечения, география, поведение) влияют на их возвращаемость.
- Сформулировать выводы и практические рекомендации для команды маркетинга по повышению лояльности пользователей.
